# Utforsk Brøset

Interaktivt kart over den nye bydelen Brøset i Trondheim, laget som prototype for broset.no.

- 24 steder med faktaboks, bildegalleri og kildehenvisninger til kvalitetsprogram og reguleringsplaner
- Omriss av de fire nyboligprosjektene i salg, med lenke til prosjektsidene
- Fungerer på PC og mobil

Åpne `index.html`, eller se den publiserte siden via GitHub Pages.

Alle bilder er av illustrativ karakter, endringer vil forekomme.
